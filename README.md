# Credit card Fraud Detection

**📌 Overview**

This project focuses on detecting fraudulent credit card transactions using Machine Learning.
With the increasing number of online transactions, fraud detection has become a critical task for financial institutions.
The model is trained and evaluated on real-world transaction data to classify whether a transaction is fraudulent or genuine.

**⚙️ Tech Stack**

Python 3.8+

Libraries: NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn

Modeling: Logistic Regression, Random Forest, Decision Trees, etc.

Evaluation Metrics: Accuracy, Precision, Recall, F1-score, ROC-AUC

**📊 Dataset**

The dataset contains credit card transactions over a period of time.

Each transaction is labeled as:

0 → Genuine

1 → Fraudulent

Due to privacy concerns, the dataset is not directly uploaded here. You can download it from Kaggle – Credit Card Fraud Detection Dataset

**🚀 Features Implemented**

✔️ Data preprocessing and cleaning

✔️ Handling class imbalance using SMOTE / undersampling

✔️ Feature scaling (StandardScaler)

✔️ Model training with multiple classifiers

✔️ Performance evaluation using confusion matrix & ROC curves

✔️ Insights on fraud detection challenges

**📈 Results**

The best-performing model achieved:

High Recall (fraud detection rate)

Balanced Precision (minimizing false positives)

Fraud detection is treated as a class imbalance problem.
